## What was asked, and what is delivered

(a) **Printing.** `File > Print…` and `File > Save as PDF…` now exist. Both build the
same portable `app::PrintJob` (`app::build_print_job`) and run it through one offscreen
`PrintView` in an `NSPrintOperation`; the PDF route is the same operation with an
`NSPrintSaveJob`. The existing `File > Export PDF (Sheet/Gantt)…` still works and now
uses the same `app::PageSpec` for page size/margins/row height, so Export PDF and print
cannot drift. The page layout is plain C++ and headless-tested.

(b) **Linked-pin warning.** `app::warning_for_start_edit()` is a pure function over
`PlanInput` returning none / clamped-to-predecessor / manual-task-will-be-rescheduled /
no-effect, with the clamped date. The shell calls it from the single Save path and shows
one `NSAlert` before writing when any edit warns (cancel aborts the save). **The writer
is unchanged**: `save_date_edits` still stores the exact SNET constraint.
