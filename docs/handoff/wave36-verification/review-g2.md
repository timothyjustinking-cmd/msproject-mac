**R36G2-1 (Medium)** tests/roundtrip_props.cpp:807-930 (`test_insert_pairs`, `whole_stream` false for 7 rows). The lift rule (b) asks for byte-for-byte equality outside exact-field masks. For the seven baseline-shape rows the test compares only the appended record, header words +0/+4/+12, and port-vs-control; it never compares the port with Project's stream outside the append. Port and Project differ in 25 to 35 bytes of the old region in every one (diff_pairs.py / harness): records 0x00010001..0x00010004 (table size words), 0x01000003, 0x02400024, 0x02401395/96/97/9f (baseline slots), 0x024013bd. These are Set Baseline's own fields (wave 37), not the insert, but no mask names them. The record and props_edit.h say the port equals Project's "every control byte", which is not what the test proves. Only the two note pairs are whole-stream. Fix: for each baseline row add exact (record id, offset) masks for those Set Baseline fields and compare the rest of the stream, or reword the record to say the old region is unverified.
