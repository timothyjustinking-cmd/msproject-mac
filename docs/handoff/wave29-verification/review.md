# Wave 29 independent review (`git diff wave28..wave29`, tip c3ae1cf)

This is a read-only review. The only repo file written is this one. The scratch
scripts live in the session scratchpad, not in the repo: a minimal CFB reader, the
null-save mask audit, the fixture privacy scan, the link-row count and the 0 %-row
word dump. I formed the findings below before reading the wave's own CLOSE review
and its "Found, not fixed" list. Where I agree with an item there, I say so.

## Verdict

G0 did most of what rule 1 asked for the wave-28 shapes. The actuals and outline
save-pair tests now compare every owned stream with PROJECT's file. Every other
stream goes through a null-save mask built from the control and its committed
no-edit save. After W29-1.0b, the wave's own logs show no whole stream still waved
through: the 50 actuals expected failures are all the refused 25 -> 60 pair, the app
outline test has none, and the core round trip has 7 expected failures, all on its
chained input. I re-derived the mask from the committed fixtures. In the 22 enabled
pairs it hides no edit effect: the only masked bytes where Project's edit save differs
are per-save counter words. The Props14 masked tail equals the control in every pair.
The CLOSE gates and CI claims check out against `build/w29/` (hash `5301...9c5c`).

The commands were widened further than the pairs measure, though. All four automatic
outline pairs are link-free files (0 live `TBkndCons` rows). Yet the automatic
indent/outdent rewrites slack and late dates on every automatic row with a formula
that only holds when there are no links. No refusal checks for links. The outline
writer has no progress logic, and nothing refuses moving a row that already has
progress. Indent tombstones the new summary's only assignment without checking that
it is Project's placeholder. The edit model's guard tests only for work above zero,
so a zero-work real assignment, such as a cost resource, is deleted on save.

Every actuals save rewrites the roll-up of every summary that has a progressed leaf.
It uses a Resume/Stop rule measured with one progressed leaf. The resource-loaded
contour is one data point generalised to any duration. A date update that computes
0 % on a 0 % row writes the measured 100 -> 0 shape, a transition no pair covers.
`add_task_link` still writes a byte rule the wave's own measurement falsified.

**Counts: Critical 1 / High 6 / Medium 4 / Low 8.**

## Checks that passed (spot-checked)

- **The owned-stream comparisons are against Project's file**, with a named
  canonicalisation (identity GUIDs, opaque step tokens, the resource identity link)
  and no comparison against the control (`app/app_edits_actuals_tests.cpp:760-1000`).
  The pair test also checks the edit model's targets: percent and elapsed ticks.
- **The null-save mask is derived only from control vs null.** It is built per pair,
  so it is no broader than that pair's measurement, apart from the 16-byte granularity
  (R29-12). DocumentSummaryInformation has zero noise in all pairs and is compared
  exactly. The port reproduces its 2-546 effect bytes.
- **W29-C2** holds: only exactly 40 or 80 with a whole step percent pass, on a stored
  60 % automatic top-level row with ActualStart = Start2 and a progress block. A
  lowering from any other block shape, or on a real assignment, throws.
- **Dialogs:** Text Styles and Bar Styles apply only to the session view
  (`PlanDocument::set_session_gantt_style`), and no app_qt save path reads that style.
  Gridlines, Visual Reports and Compare Projects are inert. Every primary action
  (Save Data, View, New/Edit/Manage Template, Modify, Browse, OK) is disabled with
  "not implemented in this port". Page Setup edits the shared print layout, not the
  `.mpp`. The changed gates (ribbon inventory, split view, UX, project dialog) were
  retargeted to the measured transitions, not loosened.
- **Privacy in the range:** 0 hits in the 56 added or changed test-data files and in
  all added text lines and commit messages for the full name, the profile folder and
  the company folder. The five `w29-*.measures.json` files carry numbers and
  repo-relative paths only.
- **CI:** both workflows are green on `7e14aaa` (`close-ci4-{ci,qt}-status.json`,
  head sha matches).
