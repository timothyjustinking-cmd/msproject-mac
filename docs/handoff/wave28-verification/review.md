# Wave 28 independent review (`git diff wave27..wave28`, tip 69a4aac)

Read-only review. Nothing in the repo was changed except this file. Scratch scripts
(a minimal CFB reader, the fixture scanner and the path-check falsification) live in
the session scratchpad, not in the repo.

## Verdict

Wave 28 is careful work, and the measured part holds up. The four task-table streams
of the actuals saves, the six owned outline streams and the new-task-mode Props record
really are compared with Project's own files. The privacy re-derivation of the seven
fixtures is clean at both UTF-16 alignments and as ANSI. The in-place
neutralisation of `synthetic-calendars.mpp` touches only path and name text. G5's
deferral is honest, and the split button stays disabled. But standing rule 1 is not
met for the three main save paths it enables. The tests compare every field Project
changes outside the "owned" streams against the **control**, not against Project's
file. That covers Task Fixed2Meta, the FixedMeta flag at +44 and TBkndAssn actual
work for the actuals save, and TBkndAssn tombstones for the outline save. No Project
reopen of the port's actuals, outline or new-task-mode save exists, although the
headers say one exists. The enabled commands also accept row shapes that no pair
measured: leaves under a summary, tasks with work, rows that already have progress,
auto-scheduled indent/outdent, and the Update Project "Selected tasks" scope. In some
of these the date-update commands can overwrite or erase recorded actuals. The new
fixture path check has a dead UTF-16 user-profile branch.

**Counts: Critical 0 / High 4 / Medium 3 / Low 5.**

## Checks that passed (spot-checked)

- **The quoted check counts are true.** Actuals 874 (432 at W28-1.2), outline 942,
  new-task mode 1933, outline round-trip 560/0 all appear in `build/w28/*.log`. The
  CLOSE log `build/w28/close-fresh-gates.log` shows 52/52 core, 20/20 app and 24/24 Qt
  (Qt partly read), `plan_recalc` 512/266 and selftest 53/0.
- **`synthetic-calendars.mpp` in-place change.** 215 bytes differ between `wave27:`
  and `wave28:`, all in the two UTF-16 save-path strings (offsets 2694-2895 and
  133632-133833, now `C:\w19\synthetic-calendars.mpp` padded with spaces), the two
  ANSI SummaryInformation name values (4256, 4276) and one UTF-16 value (24548). No
  scheduling byte moved, so re-pinning the hash in `check_fixtures.py`,
  `engine_diff.py` and the README is justified.
- **W28-0.3.** The FAT resize to `fat_sectors * (kSector/4)` is exactly what the
  write loop reads and is at least `total`.
- **W28-0.2.** Sibling ordering by the ID column is applied in both the MPP14 and
  the MPP12 paths.
- **New-task mode (W28-3.1).** The port changes exactly one stream, the Props record
  is compared with Project's record by record (masking only the two opaque id
  payloads), and the missing-record case refuses before queueing. Project's other 14
  changed streams are save churn and are asserted equal to the control (the same
  pattern as R28-1, but low risk here).
- **Split Task stays disabled.** It is `enabled=false` at `app_qt/ribbon_bar.cpp:291`,
  carries the decision-9 tooltip, and its handler at `app_qt/main_window.cpp:2049` is
  a no-op. The pin TSV still lists it as 0.
- **Undo display restore.** `without_structural_edits` restores percent and outline
  fields for undone edits. I found no stale-display path, since the display is
  rebuilt on every push, undo and redo.
